Data Cleaning and Pattern Match

For functions that separate one column into two columns, change “$1” to “$2” to get the second column. Otherwise do not edit the “regex pattern” or “replacement string” if you do not know what they are.

Level Calculation

  • If P1 → Level 1, input 0 for the shift amount.
  • If P1 → Level B3, input -1 for the shift amount.
  • If S1 → Level 7, input 6 for the shift amount.
  • If S4 → Level 1, input -3 for the shift amount.
